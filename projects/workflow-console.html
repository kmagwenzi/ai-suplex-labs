What it is

A local control surface over your AI-Suplex 777 vault. It reads and writes only through declared MCP actions — never behind your back.

Workspaces

Create a workspace (Daily Work, Project, Quick Task, or Review) from a structured form with title, mission, focus, and tasks — not manual file editing.

Today

See active workspaces, today’s tasklist, recent sessions, and pending memory proposals in one place at a glance.

Commands

Run and compose the 23 AI-Suplex workflow commands as structured data (suplex://commands, MCP contract 1.3.0) — you choose what runs.

What it writes to your vault

The Workflow Console operates your local vault. It is not a cloud dashboard, and it does not replace your agent.

What it is not

Clear boundaries between the local Workflow Console, hosted client operations, and coding agents.

  • Not the Agents Terminal The Agents Terminal client view at app.ai-suplex.co.zw (mission control and WQR tenant operations) is a separate product. Naming reflects architecture, not build history.
  • Not a cloud dashboard Runs on localhost against files on your own drive and works without an internet connection.
  • Not an agent replacement Operates the vault structure and workflow handoffs; your AI agents still execute the actual tasks inside the workspace.
  • Not autonomous Proposes actions and candidate lessons, then waits for your explicit click and confirmation before promoting memory.

Frequently asked questions

Do I need AI-Suplex 777?

Yes. The Workflow Console is a local control surface built specifically for an AI-Suplex 777 vault.

Does it replace my AI agent?

No. The console organizes workspaces, command prompts, and human approvals; your agents (Codex, Claude Code, Hermes, Cursor, or Zed) still do the work inside the vault.

Does it send my files to the cloud?

No. It runs locally on your machine, connects to your vault over local stdio, and works offline.

Does the terminal CLI still work alongside it?

Yes. The console is an alternative interface over the same vault files and 3lm CLI — you can switch between buttons and terminal commands at any time.

Is the Workflow Console free?

Yes. Like AI-Suplex 777, the Workflow Console is free for operating your local vault.

Where do I download the desktop bundle?

The standalone desktop bundle is in preparation. Use Request access to be notified when the package lands.
