What the Workflow Console does.

The console is a local window over your AI-Suplex 777 vault. It holds no separate database and runs no hidden model calls — the pipeline strip is the navigation, and the AI-Suplex Commands are the verbs.

01 · Workspaces

Create from a form, not a file edit

Open a Project or Quick Task workspace by filling in the lane, title, slug, mission, and initial tasks. The vault writes both the instance context file and the daily tasklist automatically.

02 · Today

The day’s state at a glance

See the 10-stage workflow pipeline strip, active workspaces sorted newest-first, today’s tasklist, recent sessions, last shipped artifact, and the live 3-layer memory pulse.

03 · Commands

All 23 AI-Suplex commands as data

Run or compose all 23 AI-Suplex Commands as guided actions over the suplex://commands resource (MCP contract 1.3.0) — 7 dispatchable prompts and 16 copy-ready patterns with required field checks.

What it writes to your vault.

The Workflow Console operates your local vault through a single persistent stdio MCP server (ai-suplex-harness). It is not a cloud dashboard, and it does not replace your agent. Every file write is declared in MCP contract 1.3.0 and tied to a human action:

  • ✅ Creates workspaces — suplex_workspace_create (declared file-write in MCP 1.3.0)
  • ✅ Reads tasklists, sessions, and vault state — suplex://context, suplex://tasklists, suplex://threads, suplex://commands
  • ❌ Nothing in the cloud — localhost only, works offline (verified with Wi-Fi disabled)
Action What happens in your vault Your control
Create a workspace Writes a workspace brief in Context Kick-start/Active/ and an optional daily tasklist via suplex_workspace_create. You define the lane, mission, and tasks
Read vault state Reads workspaces, tasklists, sessions, pipeline stage state, and the 23 command documents over MCP resources. Read-only (no background mutations)
Run or compose a command Assembles an AI-Suplex: <Command> prompt from your inputs or dispatches a selected workflow tool. A copied prompt never marks a stage done until the output file exists. You choose and confirm
Capture a session Records session outcomes, artifacts, and candidate lessons via suplex_capture and suplex_close. You review before promotion
Promote a lesson / ritual Elevates approved knowledge to durable semantic/procedural memory via suplex_promote or suplex_ritual (requires approved: true). You approve by typing explicit confirmation (PROMOTE)

What the Workflow Console is not

Not a cloud dashboard

Runs on localhost over local stdio and works offline. Nothing about your vault lives on an external server.

Not an agent replacement

The console operates the vault and composes commands; your coding or research agents still perform the execution inside it.

Not the Agents Terminal client view

Not autonomous

It never runs an LLM behind the scenes or promotes lessons without your explicit typed confirmation gate.

Questions, answered.

Do I need AI-Suplex 777 to use the Console?

Yes. The Workflow Console is a graphical control surface for an AI-Suplex 777 vault. 777 is free and open source.

Does it replace my AI agent?

No. The console creates workspaces, tracks pipeline stages, and composes commands; Codex, Claude Code, Hermes, or your preferred agent does the work.

Does any of my vault data go to the cloud?

No. The console runs locally on your machine, talks to ai-suplex-harness over stdio, and works completely offline.

Do the terminal CLI and Obsidian still work?

Yes. It is an alternative window over the exact same Markdown files — not a fork or replacement for node Tools/3lm.js or Obsidian.

How much does the Workflow Console cost?

It is free, as the point-and-click surface for the free AI-Suplex 777 edition.

When will the standalone download be available?

The desktop bundle is currently in preparation (P008). Request access above to run the local build or be notified first when the packaged installer ships.
