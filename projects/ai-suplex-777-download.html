03 · Quick start

Requirement: Node 20+ (Node 22+ tested)

Unzip the release, run the installer into a target folder, and verify your first context brief: 

unzip ai-suplex-777-v2.10.0.zip && cd ai-suplex-777
bash install.sh /path/to/my-vault
cd /path/to/my-vault && node Tools/3lm.js start --context
Expected output (exit 0, 1.6 s — measured cold, 2026-11-18): ✓ Context fresh.
Windows PowerShell & in-place initialization options

Windows PowerShell: after extracting the archive, run .\install.ps1 inside the unzipped folder.

In-place initialization (directly inside the extracted folder): run node Tools/initialise-vault.js (creates period.md + 40 vault folders), node Tools/vault-index.js --current, and node Tools/3lm.js start --context.
