3. Install and start

Requires Node 20+ LTS (Node 22 tested). Works in Obsidian or any code editor. Extract the ZIP, initialise the vault, build the index, and load your first brief:

Release ZIP quick start 
unzip ai-suplex-777-v2.10.0.zip && cd ai-suplex-777
node Tools/initialise-vault.js       # period.md + 40 folders
node Tools/vault-index.js --current  # the file index
node Tools/3lm.js start --context    # your first brief
Expected output 
$ ✓ Context fresh.
Installing from a git clone? (install.sh / install.ps1)
Repository installer (macOS / Linux / Windows) 
# macOS / Linux / Git Bash (custom path or default ./ai-suplex-vault)
bash install.sh ~/AI-Suplex-777

# Windows PowerShell
.\install.ps1
