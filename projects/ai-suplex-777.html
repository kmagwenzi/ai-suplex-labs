A portable workspace for AI agents.

AI-Suplex 777 is a file-first execution framework. It turns your work into workspaces, captures what happened, extracts lessons, and makes the next session start smarter. It works alongside the agents you already use — it does not replace them.

What you get

A portable workspace vault

A normal folder of Markdown, tasklists and artifacts. Move it, back it up, sync it, open it in Obsidian.

Agent-agnostic execution

Point any file-capable agent at AGENTS.md. 777 provides the workflow, memory and guardrails; the agent does the work.

Human-approved memory

777 captures what happened and proposes lessons — and promotes only what you approve. You stay in control of what becomes memory.

Structured task continuity

Workspaces, tasklists, episodes and next actions — so unfinished work resumes instead of restarting.

Local-first maintenance

Validate the vault, refresh the index, back up, export. Everything runs on your machine.

Optional knowledge graph

A lightweight way to explore what relates to what. Optional — the core value is continuity, and the graph is a later unlock.

Questions, answered

Do I need a specific AI agent?

No. 777 is agent-agnostic — any agent that can read and write files can run a workspace.

Where does my data live?

In your vault: plain Markdown and local databases on your machine. Nothing is required in the cloud.

Does it decide things for me?

No. 777 captures what happened, proposes lessons, and promotes only what you approve.

What about the knowledge graph?

Optional. The core value is continuity — workspaces, capture, lessons, maintenance. The graph is a later unlock.

How much does it cost?

Free. 777 is MIT-licensed open source — download it, own it. AI-Suplex Ultra is the paid intelligence layer.

Can I move my vault?

Yes. It is a folder of files — copy it, sync it, back it up. It outlives any tool.
