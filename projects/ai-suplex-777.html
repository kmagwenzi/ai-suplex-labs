A portable workspace for AI agents.

AI-Suplex 777 is a file-first execution framework whose core function is to execute and run the AI-Suplex Workflow. It turns your work into structured workspaces, captures what happened, extracts lessons, and makes the next session start smarter. It works alongside the agents you already use.

Layer What it does
Workspace Defines the mission, daily tasklist, active instance context, and target outcome in plain files you own.
Memory Captures episodes, candidate lessons, decisions, and reusable knowledge across a three-layer stack (Episodic → Semantic → Procedural).
Workflow Starts, executes, captures, promotes, and maintains work so every session follows a repeatable assembly line.

How 777 runs the AI-Suplex Workflow.

Create a workspace → Kickstart it → Capture the outcome → Learn → Return smarter

In the AI-Suplex Workflow, a weekly plan is broken into focused daily tasklists (15–20 tasks sized for a single session). 777 drives the complete loop from Phase 0 context priming through artifact capture and human-gated memory promotion.

01 · Start

Prime the context core

Run 3lm start --context to load verified lessons, recent episodes, and active tasklists before writing a prompt.

02 · Execute

Run the session tasklist

Execute your daily tasklist with AI-Suplex: <Command> triggers, 14 role skills, or your preferred coding agent.

03 · Capture

Produce tracked outputs

Every session produces visible outputs: work-in-progress Artifacts, Insights, reusable B-Bombs, and a Session End Report.

04 · Learn

Extract session lessons

3lm end and 3lm learn write the episodic record and extract candidate lessons into Memory/lessons.md.

05 · Promote

Approve durable memory

You review and approve high-signal lessons via 3lm promote, elevating them into semantic and procedural memory.

06 · Index & Return

Save context across lanes

Instance-scoped Save Context and 3lm sync commit your thread state (Daily, Project, Random, Realist) so the next session starts smarter.

This is real output from the 3lm memory loop — not an abstract diagram. Step through the 90-second walkthrough below to see how one session's work becomes the next session's starting context.

Step 1 of 3 · Phase 0 Context Core (3lm start --context) ai-suplex-vault 
$ 3lm start --context
✅ Context fresh.

LESSONS
· Screen a remote role in the order region → language → seniority → stack.
· A background build lane must declare its hour budget before the first commit.
· When a spec says an artifact is generated by a tool, verify the tool writes it.

RECENT EPISODES
· 2026-10-13-0815-ship-the-install-gate (4/5)

ACTIVE TASKLISTS
· 2026-10-16-ship-the-install-gate-tasklist.md
$ 3lm end --session "ship-the-install-gate" --score 4
✅ Episode recorded: Memory/episodes/2026-10-13-0815-ship-the-install-gate.md

$ 3lm learn
✅ Extracted 2 candidate lessons from session report:
  [L-104] A background build lane must declare its hour budget before the first commit.
  [L-105] When a spec says an artifact is generated by a tool, verify the tool writes it.
Status: Awaiting human review in Memory/lessons.md
$ 3lm promote --min 70
✅ Human approval verified.
Promoted 2 lessons → Semantic & Procedural memory.

$ 3lm sync
✅ Context Kick-start synced. Next session will start with updated context core.

Every lesson listed was learned in an earlier session. That is the core value of 777.

Core capabilities — outcomes, not internals.

Portable workspace vault

A normal folder of Markdown, tasklists, artifacts, and local databases. Move it, back it up, sync it with Git, or open it in Obsidian — your vault, your files, your control.

Agent-agnostic execution

Point any file-capable agent at AGENTS.md. 777 provides the workflow, memory loop, and guardrails; the agent you already trust does the work.

Human-approved memory

777 captures what happened and proposes candidate lessons — and promotes only what you approve. You stay in control of what becomes permanent memory.

Structured task continuity

Workspaces, daily tasklists, episodes, and instance-scoped context files ensure parallel windows never clobber each other and unfinished work resumes cleanly.

Local-first maintenance

Validate the vault, refresh the index, archive completed sessions, back up, and export. Everything runs locally on your machine with zero cloud lock-in.

Optional knowledge graph

Lightweight exploration of what relates to what across your vault. Explicitly optional in the client-ready release — continuity comes first, and the graph is a later unlock.

Questions, answered.

Do I need a specific AI agent?

No. 777 is agent-agnostic — any agent that can read and write files can execute a workspace via AGENTS.md.

Where does my data live?

In your local vault: plain Markdown files and local databases on your machine. Nothing is required in the cloud.

Does it make decisions for me?

No. 777 captures what happened, proposes candidate lessons, and asks for your approval before promoting anything to durable memory.

What about the knowledge graph?

It is optional. The core value of 777 is workspace continuity, session capture, lessons, and maintenance. The graph is a later unlock when you want it.

How much does 777 cost?

777 is free and MIT-licensed open source. AI-Suplex Ultra is the paid intelligence layer built on top of it.

Can I move or back up my vault?

Yes. Because your vault is a normal folder of plain files, you can version it with Git, sync it across devices, open it in Obsidian, and keep it forever.
