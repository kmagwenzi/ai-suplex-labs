03 · First run

  1. Run the app. The first screen is Setup.
  2. Choose Choose folder… and pick the folder that holds period.md — your AI-Suplex 777 vault.
  3. Press Use this vault, then reload the console.
  4. You are on Today: the pipeline, your memory stack, your last shipped artifact.
# AppImage
chmod +x ai-suplex-777-console-0.1.1-x86_64.AppImage
./ai-suplex-777-console-0.1.1-x86_64.AppImage

# no FUSE? run it extracted
./ai-suplex-777-console-0.1.1-x86_64.AppImage --appimage-extract-and-run

# zip
unzip ai-suplex-777-console-0.1.1-x64.zip -d ~/console
~/console/ai-suplex-777-console

No vault yet? The app opens on a sample vault on first launch so you can walk the line, and says so in Setup. The free 777 vault is the real thing.

04 · What it does to your vault

  • It reads. Pages are rendered from the vault through the MCP harness — never a copy, never a cache it trusts.
  • It writes only when you ask. Creating a workspace, capturing an artifact, closing a session — each is a named action, and each lands in the vault's own folders.
  • One setting lives outside it. Which vault to open, in the app's user-data directory — never a file in your notes.
  • No account, no telemetry, no network call for your data. The console runs entirely on your machine.

It is the same console as the source build — same contract (mcp v1), same test suite, and the harness it talks to is bundled inside the app.

05 · What is not there yet

  • Linux x64 only. Windows and macOS targets are configured but not built, and not signed.
  • Unsigned. Your system may warn the first time. That is the missing signing certificate, not the app.
  • v0.1.1 — a first packaged build. Expect rough edges, and tell us about them.
