03 · First run

  1. Run the app. The first screen is Setup.
  2. Choose Choose folder… and pick the folder that holds period.md — your AI-Suplex 777 vault.
  3. Press Use this vault, then reload the console.
  4. You are on Today: the pipeline, your memory stack, your last shipped artifact.
# Windows — run the installer, then launch "AI-Suplex 777 Console"
# SmartScreen may warn: More info -> Run anyway (the build is not signed)

# macOS — open the .dmg, drag the app to Applications
# Gatekeeper may block it: System Settings -> Privacy & Security -> Open Anyway

# Linux
chmod +x ai-suplex-777-console-0.1.1-x86_64.AppImage
./ai-suplex-777-console-0.1.1-x86_64.AppImage

No vault yet? The app opens on a sample vault on first launch so you can walk the line, and says so in Setup. The free 777 vault is the real thing — the console reads it, and writes only when you ask it to.

04 · What is not there yet

  • Nothing is signed. SmartScreen and Gatekeeper will warn the first time. That is the missing certificate, not the app.
  • macOS is Apple Silicon only. An Intel Mac build is not made yet.
  • v0.1.1 — the first packaged build. Expect rough edges, and tell us about them.
  • Windows and Linux builds are not notarised or signed, so a managed machine may refuse them outright.
